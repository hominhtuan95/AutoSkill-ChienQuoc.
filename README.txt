AUTO SKILL 3 - CHIEN QUOC 1.01.92 (BAN THU NGHIEM)

Yeu cau: Windows 10/11, .NET 8 SDK de bien dich.

1. Mo terminal tai thu muc nay.
2. Chay: dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
3. File EXE nam tai bin\Release\net8.0-windows\win-x64\publish\AutoSkill.exe
4. Mo tool, nhap mot phan tieu de cua so game, cai 3 phim va khoang cho.
5. F6 bat, F7 tat. Tool chi gui phim khi game la cua so dang duoc chon.
6. Nhan Luu de luu cau hinh.

Luu y: Chua kiem thu voi client Chien Quoc 1.01.92. Mot so game khong nhan SendInput.
Khong can thiep bo nho, khong vuot anti-cheat. Khong chay file EXE tham chieu khi chua tin nguon.
